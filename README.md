# LUNEO
Незалежний демонстраційний магазин для портфоліо NULLEXWEB. Next.js App Router, TypeScript, Tailwind CSS, GSAP/ScrollTrigger, Lucide. Англійський інтерфейс, UAH.

## Запуск
Node.js 20.9+ (рекомендовано 22 LTS).
```sh
npm ci
npm run dev
```
Відкрийте http://localhost:3000.
```sh
npm run typecheck
npm run lint
npm run build
npm start
```

## Vercel
Імпортуйте цю директорію як окремий Git-репозиторій, preset Next.js, build `npm run build`. Встановіть `NEXT_PUBLIC_SITE_URL` на фактичний HTTPS-домен, щоб Open Graph мав коректні абсолютні URL. Деплой у межах цієї роботи не виконується. Жодних API-ключів не потрібно.

## DEMO MODE і дані
Кошик зберігає тільки ID та кількість у localStorage (`luneo-cart`). Оформлення працює локально через `src/lib/orders.ts`; контактні дані не зберігаються і не передаються. Newsletter і контактна форма лише демонструють валідацію та підтвердження. Оплата, доставка та фактичні замовлення відсутні. Використовуйте вигадані персональні дані.

## CRM
`OrderService` — контракт, `orderService` — локальний адаптер. Майбутню CRM інтегруйте серверним адаптером через захищений Route Handler; API-ключі не повинні потрапляти у клієнт. Сервер має повторно перевіряти ціни, залишки, поля, авторизацію, rate limits та ідемпотентність. Поточна реалізація мережевих запитів замовлення не робить.

## Зображення
21 оригінальне AI-зображення з вбудованої генерації Codex: 3 campaign, 12 product, 4 lifestyle, 2 editorial. Локальні оптимізовані WebP у `public/images`, Next Image використовує responsive sizes, lazy loading, hero priority. Промпти та джерела записані в `image-manifest.json`. Стокові фотографії та логотипи реальних брендів не використовувалися. Зображення є концептуальними, не підтверджують реального виробництва або характеристик товарів; AI-генерація не гарантує ексклюзивних прав чи ідентичності деталей між кадрами.

## Доступність
Семантична розмітка, native dialog із focus trap/Escape, фокус-стилі, підписи полів, reduced-motion. GSAP анімації вимкнені при prefers-reduced-motion. Картки мають стандартні посилання.
